# OmniKey Vault — 后续开发计划（面向用户）

> **当前版本**：v2.6.5（2026-08-14）
> **平台范围**：Windows 10/11 (x64)
> **本文档面向用户**，不涉及内部技术实现细节。

---

## 当前状态

OmniKey Vault v2.6.3 已完成全部核心功能开发、三轮使用体验优化（P0/P1/P2）、P0 功能增强（浏览器扩展自动填充、条目管理增强、同步增强）以及 P1 安全增强（WebAuthn/FIDO2 生物识别解锁、Windows Credential Manager 集成），并修复了跨设备金库写入、编辑器关闭循环、设备密钥零化等多个关键 Bug，新增了恢复密钥解锁功能，产品从「功能实现」阶段进入「体验打磨」阶段。

- **安全核心**：双重 Argon2id KDF、XChaCha20-Poly1305 AEAD、Ed25519 签名、自定义 `.okv` 格式、凭据泄露检测、Shamir 分片恢复
- **凭据管理**：70 个平台模板、多 Profile、多保险箱、SSH 密钥、证书管理、TOTP、历史快照、密码生成器
- **同步迁移**：WebDAV / S3 / 本地文件夹三通道同步、7 种导入格式、加密容器导出
- **系统集成**：全局热键、浏览器扩展、单例模式、自包含发布、自动更新、托盘图标
- **用户体验**：命令面板、全局搜索、新手引导、快捷键速查、通知中心、安全健康报告、辅助功能（高对比度 / 字体调节 / 列表密度）
- **测试**：797/797 通过，1 万条目性能压测全部达标

## 后续规划

> v2.3.8 功能和体验优化已全面交付。以下规划围绕**更深层次的安全增强、跨平台扩展、生态集成**三个方向推进。
>
> - **P0（近期）**：用户反馈最迫切的增强项
> - **P1（中期）**：扩展使用场景的增强项
> - **P2（远期）**：战略性功能，需较大投入

---

### P0 — 近期增强（✅ v2.4.0 已交付）

#### 1. 浏览器扩展增强

| 任务 | 用户价值 | 状态 |
|---|---|---|
| **自动填充网页表单** | 当前浏览器扩展仅支持搜索和复制，无法自动填充网页中的用户名/密码字段。增强后可直接在网页中一键填充凭据，减少手动复制粘贴 | ✅ v2.4.0 |
| **扩展图标状态指示** | 扩展图标根据保险箱锁定/解锁状态显示不同颜色，一眼看出是否可用 | ✅ v2.4.0 |
| **最近使用条目快速访问** | 扩展弹窗中显示最近复制过的条目，无需每次搜索 | ✅ v2.4.0 |

#### 2. 条目管理增强

| 任务 | 用户价值 | 状态 |
|---|---|---|
| **条目列表虚拟化** | 当条目数量超过 500 时启用虚拟化列表，保证万级条目下流畅滚动 | ✅ v2.4.0 |
| **条目拖拽到文件夹** | 支持从条目列表直接拖拽条目到侧边栏文件夹，快速移动归类 | ✅ v2.4.0 |
| **多标签页视图** | 支持同时打开多个条目详情标签页，方便对比不同条目的信息 | ✅ v2.4.0 |
| **自定义字段拖拽排序** | 编辑器中的字段支持拖拽重新排序，当前只能通过删除后重新添加来调整顺序 | ✅ v2.4.0 |

#### 3. 同步增强

| 任务 | 用户价值 | 状态 |
|---|---|---|
| **同步冲突批量处理** | 出现多个冲突时提供「全部采用本地」「全部采用远端」「逐个确认」三种模式 | ✅ v2.4.0 |
| **同步日志可视化** | 同步完成后可查看详细的同步日志（拉取/推送/合并了哪些条目、是否有冲突） | ✅ v2.4.0 |

### P1 — 中期扩展

#### 4. 跨平台扩展

| 任务 | 用户价值 |
|---|---|
| **移动端伴侣应用** | Android 伴侣应用，支持只读查看和复制凭据（加密同步） |

#### 5. 安全增强

| 任务 | 用户价值 |
|---|---|
| **WebAuthn / FIDO2 解锁** | 支持 Windows Hello / YubiKey 生物识别或硬件密钥解锁金库，减少主密码输入频率 | ✅ v2.5.0 |
| **EV 代码签名** | 安装包使用 EV 代码签名证书，消除 SmartScreen 警告，提升信任度 |
| **密钥库集成** | 与 Windows Credential Manager 集成，支持系统级密钥存储 | ✅ v2.6.0 |
| **定时自动备份** | 定时将金库备份到指定位置（本地 / 云端），防止数据丢失 |

#### 6. 生态集成

| 任务 | 用户价值 |
|---|---|
| **VS Code 扩展** | 在 VS Code 中直接搜索和插入 API Key，无需切换到桌面应用 |
| **Webhook 通知** | 条目过期、泄露检测等事件支持 Webhook 推送到 Slack / 钉钉 / 飞书 |

### P2 — 远期战略

#### 7. 企业能力

| 任务 | 用户价值 |
|---|---|

| **审计日志服务端** | 集中审计日志收集和合规报告导出 |

#### 8. 高级功能

| 任务 | 用户价值 |
