## 1. 仓库结构

```
OmniKeyVault.sln                     # 解决方案入口

Directory.Packages.props             # 中央包版本管理

src/
├── OmniKeyVault.Domain/             # 领域模型 — 纯值对象，无 I/O
├── OmniKeyVault.Contracts/          # 接口契约 — ICryptoProvider、IStorageProvider 等
├── OmniKeyVault.Application/        # 应用服务 — VaultService、ProfileService、EntryService 等
├── OmniKeyVault.Infrastructure/     # 实现 — SodiumCryptoProvider、VaultFormat 等
└── OmniKeyVault.Cli/                # 唯一入口项目 — 输出名 `okv`
                                     #   ├─ Gui/  — Avalonia 11 MVVM 视图（用户面向主程序）
                                     #   └─ Cli/  — 内部 CLI 解析器（集成测试 / CI 入口）

tests/
├── OmniKeyVault.Tests/              # xUnit + FluentAssertions，771 个测试
└── OmniKeyVault.Analyzers.Tests/    # Roslyn 分析器测试，20 个测试

tools/
├── OmniKeyVault.Benchmark/          # 1万条目性能压测
└── OmniKeyVault.Analyzers/          # Roslyn 安全分析器（OKV0001 + OKV0003）

templates/                            # 内置平台模板 JSON（70 个）
browser-extension/                    # Chrome/Edge/Firefox 浏览器扩展
installer/                            # Inno Setup 安装脚本 + 安装包
images/                               # 应用图标
docs/                                 # 项目文档（中文）
```

## 3. 还原、构建与测试

### 3.1 编译

```bash
dotnet restore OmniKeyVault.sln
dotnet build OmniKeyVault.sln -c Release
```

**预期输出**：0 警告，0 错误（`TreatWarningsAsErrors=true`）。

### 3.2 运行测试

```bash
# 全部 791 个测试（771 + 20 分析器）
dotnet test
```

**预期输出**：791 通过，0 失败，0 跳过。

### 3.3 性能压测

```bash
# 1万条目压测（默认 10000）
dotnet run --project tools/OmniKeyVault.Benchmark -c Release

# 调整条目数
dotnet run --project tools/OmniKeyVault.Benchmark -c Release -- 5000
```

**预期输出**：create 0.7s / unlock 0.1s / search 1.5ms / sync 0.0s — ALL OK。

### 3.4 测试环境变量

测试套件使用 `OKV_TEST_MODE=1` 切换到弱化 Argon2id 参数（32 MiB），大幅缩短执行时间。**生产代码路径不读取此变量**（`#if DEBUG` 保护）。

```powershell
$env:OKV_TEST_MODE = "1"; $env:OKV_MASTER_PASSWORD = "my-pw"; dotnet test
```

## 5. 打包与发布

### 5.1 自包含发布（推荐，零运行时依赖）

```powershell
# Windows x64 自包含发布
dotnet publish src/OmniKeyVault.Cli/OmniKeyVault.Cli.csproj `
  -c Release -r win-x64 --self-contained true `
  -o ./publish/win-x64
```

**产物**：`./publish/win-x64/` 目录，约 80 MB，包含完整 .NET 运行时 + libsodium + 70 个模板 + 浏览器扩展。

> 自包含模式（v2.2.2 引入）消除了 .NET 运行时依赖问题，用户安装后无需单独安装任何运行时。

### 5.2 Inno Setup 安装包（推荐用户分发）

**先决条件**：[Inno Setup 6](https://jrsoftware.org/isdl.php)

```powershell
# 1. 执行自包含发布（见 §5.1）
dotnet publish src/OmniKeyVault.Cli/OmniKeyVault.Cli.csproj `
  -c Release -r win-x64 --self-contained true `
  -o ./publish/win-x64

# 2. 复制文档和模板到发布目录
Copy-Item docs\*.md publish\win-x64\docs\ -Recurse -Force
Copy-Item browser-extension publish\win-x64\browser-extension -Recurse -Force

# 3. 编译安装包
cd installer
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" OmniKeyVault.iss
```

**产物**：`installer/installer_output/OmniKeyVault-Setup-2.3.8.exe`（约 45 MB）

**安装包特性**：
- LZMA2 Ultra64 压缩
- 开始菜单 + 桌面快捷方式（可选）
- `.okv` 文件关联（可选）
- 静默更新支持（`CloseApplications=force` + `RestartApplications=yes`）
- 内嵌应用图标

### 5.3 便携版 ZIP

```powershell
Compress-Archive -Path publish\win-x64\* `
  -DestinationPath publish\OmniKeyVault-2.3.8-win-x64.zip -Force
```

### 5.4 版本号管理

版本号在 `Directory.Build.props` 中集中管理：

```xml
<Version>2.3.8</Version>
<AssemblyVersion>2.3.8.0</AssemblyVersion>
<FileVersion>2.3.8.0</FileVersion>
```

Inno Setup 脚本（`installer/OmniKeyVault.iss`）中同步更新：

```
#define MyAppVersion "2.3.8"
```

### 5.5 应用图标

图标由 `tools/generate_icon.py`（Pillow）生成，保存在 `images/okv-icon.ico`（7 种尺寸：16/24/32/48/64/128/256）。

```bash
python tools/generate_icon.py
```

## 7. 故障排查

### 7.1 构建失败：warning 被视为 error

`Directory.Build.props` 设置 `TreatWarningsAsErrors=true`。任何 warning 都会导致构建失败。修复 warning，不要禁用此标志。

### 7.2 `okv.exe` 启动报 "Unable to load shared library 'libsodium'"

确保使用 `--self-contained true` 发布， libsodium native 库会自动包含。

### 7.3 Argon2id 解锁耗时 > 2s

- **正常**：v1.6 双重 Argon2id 需要约 2-4 秒（320 MiB 内存成本）
- **异常**：检查设备 RAM 是否足够（> 512 MB 可用）

### 7.4 测试失败

确保设置了 `OKV_TEST_MODE=1` 环境变量以使用弱化 KDF 参数。
