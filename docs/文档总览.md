# OmniKey Vault — 文档总览

| 文档集版本 | 日期 | 状态 |
|---|---|---|
| **2.3（当前）** | 2026-07-23 | **v2.3.8 发布**：70 个平台模板、WebDAV/S3 同步、浏览器扩展、全局热键、命令面板、791/791 测试通过 |

> **OmniKey Vault** 是一款本地优先、端到端加密的开源凭据管理工具。`okv.exe` 是唯一可执行文件；**用户面向入口是 GUI 桌面应用**（无参数启动），**内部 CLI 仅供集成测试 / CI / 调试**（详见 [内部接口规范.md](./内部接口规范.md)）。

---

## 0. 快速开始（开发者）

```bash
# 1. 克隆并进入项目
git clone https://github.com/mawenshui/omnikey-vault.git OmniKeyVault && cd OmniKeyVault

# 2. 还原 + 构建
dotnet restore OmniKeyVault.sln
dotnet build OmniKeyVault.sln -c Release    # → 0 warnings, 0 errors

# 3. 启动 GUI 桌面应用（主程序）
dotnet run --project src/OmniKeyVault.Cli

# 4. 跑测试
dotnet test                                      # → 791/791 通过

# 5. 跑性能压测（1万条目）
dotnet run --project tools/OmniKeyVault.Benchmark    # → create 0.7s, unlock 0.1s, search 1.5ms, sync 0.0s
```

完整构建 / 打包 / 故障排查见 [编译打包指南.md](./编译打包指南.md)。
